# Correcting the observed workload reversal

Frozen evidence at 5f127f1: the uniform-cut activity endpoint reduced the sum of local expected transitions from 9345.43 to 8140.73, but raised whole-design transitions from 700123458 to 705047264 on 20 EPFL designs. The result remains part of the release. The specific failure is a transfer from independent cut variables to correlated internal signals. The next change is limited to the same disjoint 11047 cuts.

## Prediction and matched control, before any new workload data

For a fanout-free cut, a function-preserving internal replacement leaves every outside signal unchanged for each stable input word. Thus the changes in node transition counts of disjoint replacement interiors add exactly for *arbitrary* pairs of primary-input words, even when a cut supplies a downstream cut. This permits a cut-local optimizer to use transitions generated by complete designs without assuming independence between cut signals.

Use four new panels of 512 pairs for selection and eight disjoint new panels of 1024 pairs for final evaluation. Seeds include the design, role and panel number. Freeze cuts, order, time budget and source files. Do not fit a numerical threshold on the evaluation workloads.

For the matched control, optimize over every minimum-gate tree for the punctured subcube under its empirical transition distribution and a maximum output-arrival deadline. Pure conjunctions allow any binary split. Contract the OR-block; every upper mixed AND splits off a nonempty pure enable subtree. For the candidate, also search every ordering of the shared minterm chain attaining the uniform all-DAG optimum. Select the configuration with lowest total calibration transitions in each respective family subject to its deadline; accept the change only if it strictly improves the current control in each of the four panels. The control begins with the original cone. The candidate begins with the selected control. When the new chain is chosen, all orders of both literal groups have been considered. Global optimality under an arbitrary workload is not claimed.

Top-down required-time allocation: compute baseline arrival times, work backward from outputs with a full-design depth limit, and propagate the chosen gate paths' requirements to cut leaves. Each changed root must meet its propagated deadline using the current reference leaf arrivals. This preserves feasibility for upstream default choices by induction. For control use the original depth; for candidate use the realized control depth. All other gates, all cut functions and test vectors are shared; one extra gate per selected shared chain. Test exact local optima and deadline feasibility on small exhaustive independent controls before the full run.

Acceptance for the application claim: preserve equivalence and global combinational depth on every design; all eligible designs participate; compare paired, strictly unseen whole-design transitions against both the original and the workload-optimized size control. Report aggregate, every design, all eight panel totals, costs and any adverse outcome. A small improvement is reported at its observed magnitude. Stable-word, zero-delay toggles and unit gate costs define the scope.
