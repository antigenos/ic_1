# Cost-conditioned continuation test for the remaining classes

At prefix budget 580 every full-support representative has a feasible circuit, and 206 have a proof. Only 1681 and 1698 remain open. Direct weighted end pruning at total budget 576 proves 197 versus the 190 from the faster 520 prefix. At this coverage a larger unconditioned library alone has a small practical advantage at best. We therefore test the dual of the registered boundary inequality on each search branch.

For each still-unresolved target class f let B_f be the smaller of the current total budget and its cheapest known witness cost minus one. If there is no witness, use the total budget. Omit targets with proven lower bound greater than B_f. Precompute
`G_i = max_f(B_f - M(i,f))` and `G_2 = max_f(B_f - D(f))`.
For a prefix carrying priced wires S at cost c, every strictly extending optimal circuit uses either one later root operand and a wire from pins or S, or two later root operands. The first-crossing argument thus gives the necessary condition
`c <= max(G_2, max_{p in pins or S} G_class(p))`.
The maxima commute because only one earlier root operand occurs in this relaxation. After adding a wire v the right-hand side updates by a single maximum. At a rejected child still evaluate the free root with v and every earlier operand. A root ignoring v would have a cheaper prefix. This preserves all possible improvements and allows earlier certification than a uniform depth limit. Compute M independently here by fixing one representative of i and enumerating every normalized nonconstant q, recording w(q) for the five possible output classes. Signed equivariance gives the same minima as the cofactor subcube derivation.

Use the same end-pruned direct engine, initial witnesses, target set, costing, last-gate handling and build options in both arms. Toggle only the branch continuation limit (uniform versus target-conditioned). Recompute the prefix inside the process, count setup, both searches and export, and retain the standalone direct comparator. Select the 520 prefix because the pilot reached 207 witnesses there in 6.37 s, before the more expensive 580 prefix. In an automatic run take the maximum finite unresolved witness as the final budget; if some witnesses are missing, add one minimum paid-gate price to the maximum available upper bound. If a class is still open raise the budget by at least that minimum price and repeat with the saved bounds. This schedule is a pilot-informed choice. It does not use any known optimal answers or the direct control as an input. Recheck all three-input costs, then run on the full four-input family. Record adverse timings as well as improvements.
