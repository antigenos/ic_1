## 本轮登记

原项目已验收至阶段 15。单独的后续工作复用其阶段 1–7 的来源、成本分解、逐行重放和对照；本目录只发展目标内的对称化。DATE 使用 NPN 代表函数划分测试集，源码的 AddCnfSymBreakingInner 在同一门内对两个操作数排序。对同一个目标，若调换或反转某些主输入仍得到它或它的补，不同的首门功能可能描述代价完全相同的搜索分支。TCJAP 的联合关系依赖目标行和连接，未显式选取这些分支的代表。需要实际测量该重复对完整时间的影响。[DATE 作者全文](https://www.cda.cit.tum.de/files/eda/2026_date_exact_synthesis_with_optimal_switching_activity.pdf)

已有精确综合使用对称输入首次使用排序，NPN 分类及 SAT 对称破除也均有先例。本次检验在零行正规化及逐门折叠计数约束下，目标所容许的带相位输入变换能否压缩首门功能的候选集合，在相同预算下保留所有原有最优值。原创性主张仅能由进一步对照支持。[精确综合与已有对称约束](https://si2.epfl.ch/~demichel/graduates/theses/winston.pdf) · [NPN 类与精确综合](https://si2.epfl.ch/demichel/publications/archive/2017/07965003.pdf)

**阶段 8–10 的判断。** 对每个保持目标输出或其补的变换，在每个节点上把变换后的真值按照第零行正规化，并将极性吸收到后继门。五种正规化二输入门对此变换封闭。每个节点的折叠计数、所处拓扑位置、门数以及完整活动度均保留。首门的每个轨道只需保留真值数值最小的功能。转入完整求解前，逐行构造等价见证，检验正规化、非对称门次序、目标补和共享扇出。若逐门代价或可实现性出现反例，撤回规则。在含已知结果的函数上比较无相位和带相位的轨道，记录规则无能为力的情况。

**阶段 11–13 预登记。** 把该规则单独接入冻结的模式 2 求解入口。对原版和强化版保留既有数据，本轮直接比较冻结 TCJAP 和增加首门约束的版本。0189 为论文代表，6996 为全奇偶函数，0019 为中等耗时的常规函数。另选编号最小的稳定子平凡的四输入代表作无触发对照。每个输入先进行 ABBA 反序配对，完整进程墙钟单次上限 30 秒，各配置固定同一核心。另测无相位与关闭机制消融；所有完成解逐行验真与活动度。支持独立增益后才扩大输入覆盖。对完全平凡的稳定子，该机制只能产生启动开销。时间和完成数以实际数据为准。
