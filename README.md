# DATE 2026 低活动度精确综合与 TCJAP 独立复现

本分支交付从 Walter、Feldmeier 和 Wille 的 pexact 作者代码到 TCJAP 目标条件联合推理的独立重建。固定原版、强化对照和重建版均可从公开源码与本仓库补丁编译。主实验在 AMD Ryzen 9 8945HX、Windows 11、GCC 16.2.0 上运行。每类每种方法限时 300 秒，每个函数的各方法依次使用同一逻辑核。

| 方法 | 完成数 / 208 | 超时数 | 含超时的总墙钟成本 |
|---|---:|---:|---:|
| 锁定的 DATE 作者原版 | 67 | 141 | 46,100.71 秒 |
| 直接枚举与支持度剪枝的强化对照 | 72 | 136 | 43,995.03 秒 |
| TCJAP 独立重建版 | 80 | 128 | 42,451.69 秒 |

重建版与强化对照共同完成 71 类，配对完整时间的几何平均比为 1.592；与原版共同完成 66 类，比值为 4.386。各方法返回的 219 个电路全部经过原始输出重放，凡同一函数得到多个解，其活动度均相同。独立穷举额外证明了代表例 0189 的最优值 304 和三输入 96 的最优值 32。[逐例运行记录](evidence/e14-main/)及[独立审计](evidence/e14-main/audit.json)

强化对照在 018b 上耗时 289.44 秒，重建版超时。重建版还在 9 个共同完成的函数上较慢，其中 001e 的时间从 0.318 秒增至 0.490 秒。相对强化对照，重建版独有 9 个限时内完成的函数。TCJAP 发布的历史完成数为 71、73、94。其第一列为作者工程版，原集成、机器和计时批次也与本复现存在差异。[公开历史统计](https://github.com/qmkkk/TCJAP/blob/59e5a0e954d6a0a6711b2bdc9898db875ede6889/data/experimental_scope.json)

主批次中断后复用了 575 条有效结果，按相同配置补齐 49 条。表中总成本使用每个预登记组合的有效观察；9 次中断尝试另行保留，其中 8 次缺少终态。方法顺序按函数轮换，每个函数固定在指定核上。短实例计时含进程启动开销。[中断尝试](evidence/e14-interrupted-attempts.json)

在单独的 300 秒消融中，0189 在五种配置下均返回 304，完整规则耗时 1.724 秒，关闭新增推理后为 2.696 秒。016f 五种配置均超时。07b4 只启用提前连接排除时为 207.35 秒，完整规则为 271.06 秒，两者均得到 438；主比较的同一重建版对此例超时。两批的并发度和所在核心不同，比较开关时只使用消融批次内的配对。[逐例消融与审计](evidence/e14-ablation/)
