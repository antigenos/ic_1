### 独立最优值核查

冻结三版已经返回的 81 个不同目标中，最高见证活动度为 432。按此界限预先登记一次覆盖全部 208 个代表的独立枚举。沿用根目录 `tools/lower_bound.py` 的真值向量状态、五种正规二输入门和免费输出门，对同一批状态同时计算每个目标的下界。加入免费常量 0 并允许未使用输入扩大了可选电路集合；该集合的最低代价是作者模型的下界。相同内部真值可重用，删除重复节点不增加代价；每个互异信号的收费取决于其真值，与生成顺序无关。因此按收费信号集合去重，严格低于界限的所有状态均可展开。目标在这些状态均无法作为免费输出时，记录下界 432；若能出现则记录最小代价。下界与经过真值核验的合法见证活动度相等，就给出独立最优性证明。低于见证的下界保留为待核区间。

先用界限 304 对照原单目标检查器，两个入口均穷举 16,950 个状态，已证明冻结结果中 24 个不同目标的最优值。在 0006、001e、0189 上分别用单目标程序检查严格界与包含见证的界。正式独立枚举使用逻辑 CPU 0，与配对计时的五个核心分开。复跑命令为 `python family_bounds.py build --cap 432 --cpu 0 --output .local/repeat-bounds.json`，核验命令为 `python family_bounds.py audit .local/repeat-bounds.json`。完整 A/C 归档生成后，可再传入 `--family evidence/family-300.zip`。

活动度严格低于 432 的状态共 2,243,437 个。枚举给出的下界与冻结三版的全部 219 个返回见证相符，覆盖 81 个不同四输入目标，81 个最优值均已独立证明，其中 4 个位于界限 432。另有 8 个三版均超时的目标，其在放宽后的电路集合中能在严格界内出现；这项发现本身还没有给出作者门库下的合法电路。完整下界与按目标核验记录见 [208 类下界](evidence/family-bounds-432.json) 和 [冻结返回解的独立最优性核验](evidence/frozen-independent-optima.json)。原始三版 300 秒完成数仍为 67、72、80。
